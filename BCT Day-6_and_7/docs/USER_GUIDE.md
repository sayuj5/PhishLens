# User Guide

## Introduction
BlackFalcon is an enterprise vulnerability management platform. This guide explains how to use the web dashboard to manage your assets and vulnerabilities.

## Dashboard
The main dashboard provides a high-level overview of your network's health, including total assets, risk trends, and current scan jobs.

## Managing Networks & Assets
1. **Networks**: Go to the Networks tab to define your IP ranges (CIDRs).
2. **Assets**: The Assets tab lists all discovered devices. You can view open ports, services, and associated vulnerabilities here.

## Running Discovery
1. Navigate to the Discovery tab.
2. Select a target network and a scan profile (e.g., Fast, Deep).
3. Click "Start Discovery". You can monitor the progress in real-time.

## Assessing Vulnerabilities
1. Navigate to the Assessment tab.
2. Select the assets you want to assess and choose an assessment policy.
3. Click "Start Assessment".
4. Review the results in the Findings tab.

## Managing Findings
In the Findings tab, you can click on any vulnerability to view details, add notes, and change its status (Open, Acknowledged, Resolved, False Positive).

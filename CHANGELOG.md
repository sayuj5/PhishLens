# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),

## [v1.0.0] - 2026-07-20

### Added
- Initial Release of the PhishLens Platform.
- Completely stateless frontend architecture.
- Modular Heuristic Engine including IP, Length, TLD, Subdomain, Keyword, and Entropy detectors.
- Animated Dashboard with Risk Meter and Confidence scoring.
- PDF and JSON Export capabilities.
- Python FastAPI Backend port for API usage.
- Comprehensive Open Source documentation and GitHub templates.
